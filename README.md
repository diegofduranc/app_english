# Cuentos Interactivos

Proyecto: aplicación web para aprender inglés con cuentos interactivos.

Instalación rápida:

```bash
npm install
npm run dev
```

Estructura:
- `src/components` - componentes UI
- `src/pages` - `Dashboard`, `ChapterPage`
- `src/hooks` - `useTTS`, `useProgress`
- `src/data/chapters.ts` - capítulos de ejemplo

Agregar capítulos: editar `src/data/chapters.ts` y seguir la estructura del objeto `Capitulo`.
